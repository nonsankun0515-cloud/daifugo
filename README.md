# Cards Table

大富豪・七並べ・スピードが遊べるトランプゲームのアプリ。AIロボットとの対戦（レート戦・フリー対戦）と、友だちとのオンライン対戦ができます。大富豪はローカルルールを1つずつ選べます。PCでもiPhoneでも遊べて、iPhoneではホーム画面に置くとアプリのように使えます。

## ホーム画面に追加

- iPhone：Safari でも Chrome でも、共有ボタン →「ホーム画面に追加」
- Android・PC の Chrome / Edge：アプリのホーム上の案内（またはマイページ）の「追加する」
- LINE の中のブラウザでは追加できないので、いつものブラウザで開き直す（招待リンクには `?openExternalBrowser=1` が付いていて、LINE からはいつものブラウザで開く）

アプリの中の「追加のしかた」が、開いているブラウザに合わせた手順を出します。一度開けばオフラインでも遊べます。

## オンライン対戦

各ゲームのホームの「オンライン」→「部屋を作る」で招待リンクができます。友だちはリンクを開いて名前を入れるだけで同じ卓に入れます（足りない席はAIロボット）。
サーバーは Cloudflare Workers + Durable Objects（無料枠）。ルール判定とAIはサーバーが行い、各プレイヤーには自分の手札だけが届きます。

- `server/` … サーバー（`js/` のエンジンをそのまま使う）。公開は `server` フォルダで `npx wrangler deploy`
- `js/online-room.js` … 部屋の仕組み（サーバーとテストで共通）
- `js/net.js` … 通信（切れたら自動でつなぎ直す）

## 作り

- `index.html` と `js/`・`css/` … 開発用（ブラウザで直接開ける）
- `js/engine.js` … 大富豪のルールの判定（画面から独立。オンライン対戦でも使う）
- `js/sevens/`・`js/speed/` … 七並べ・スピード（ルール・AI・画面・ルールブック）
- `js/ai.js` … 大富豪のAIロボット（やさしい・ふつう・つよい）
- `tests/test.html` … ルールとAIのテスト
- `docs/` … 公開用のアプリ版（`py tools/build.py` で作る）

## 更新のしかた

```
py tools/build.py
```

を実行して `docs/` を更新し、GitHub に push すると公開ページに反映されます。
