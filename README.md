# 大富豪

ローカルルールを1つずつ選べる大富豪。AIロボットと対戦できます。PCでもiPhoneでも遊べて、iPhoneではホーム画面に置くとアプリのように使えます。

## 遊び方（iPhone）

1. Safariでこのリポジトリの GitHub Pages のURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動（一度開けばオフラインでも遊べます）

## オンライン対戦

タイトルの「オンライン対戦」→「部屋を作る」で招待リンクができます。友だちはリンクを開いて名前を入れるだけで同じ卓に入れます（足りない席はAIロボット）。
サーバーは Cloudflare Workers + Durable Objects（無料枠）。ルール判定とAIはサーバーが行い、各プレイヤーには自分の手札だけが届きます。

- `server/` … サーバー（`js/` のエンジンをそのまま使う）。公開は `server` フォルダで `npx wrangler deploy`
- `js/online-room.js` … 部屋の仕組み（サーバーとテストで共通）
- `js/net.js` … 通信（切れたら自動でつなぎ直す）

## 作り

- `index.html` と `js/`・`css/` … 開発用（ブラウザで直接開ける）
- `js/engine.js` … ルールの判定（画面から独立。オンライン対戦でも使う想定）
- `js/ai.js` … AIロボット（やさしい・ふつう・つよい）
- `tests/test.html` … ルールとAIのテスト
- `docs/` … 公開用のアプリ版（`py tools/build.py` で作る）

## 更新のしかた

```
py tools/build.py
```

を実行して `docs/` を更新し、GitHub に push すると公開ページに反映されます。
